# TransportModels 深关断 Poisson 线搜索与载流子行耦合审计

日期：2026-08-23

## 审计对象与复现方法

- 器件与偏压：TransportModels DD，`Vg=-0.68 V`、`Vd=1.1 V`。
- 原始失败：第 7 个 Newton 更新后，第 8 次线搜索在 `alpha=1` 至
  `1/4096` 的 13 个候选点全部拒绝。
- 为取得失败瞬间的逐行数据，在独立输出目录使用当前可执行文件重跑，
  仅把 `carrier_row_convergence.mode` 从 `report` 临时改成 `enforce`，使失败
  状态直接导出 169 条内存态违规行。该开关不参与此前 7 次 Newton 更新或
  线搜索 merit 计算，因此数值轨迹与原始计算一致；原始失败原因仍是
  `line_search_non_decrease`。
- 正式内存态数据与写盘重启态数据分开统计，避免重启舍入污染结论。

## 关键结果

| 指标 | 正式内存态结果 |
|---|---:|
| Poisson 块 L2 残差 | `1.4768533229445537e-11` |
| 电子连续性块 L2 残差 | `4.601041179501614e-17` |
| 空穴连续性块 L2 残差 | `9.816812142505154e-17` |
| 合并残差 | `1.4768533229843475e-11` |
| 源项限定载流子违规行 | 169（电子 157、空穴 12） |
| 最大局部违规比值 | `1.640304017149006`，电子，节点 1888 |
| Poisson 前 10 热点与违规节点重合数 | 1 |

Poisson 块比两个载流子块大约 5 个数量级。当前配置未显式给出三块
`residual_scale`，代码会取 `max(initial_block_norm, 1)`；本算例三个尺度均为
1。因此 line-search merit 实际由原始 Poisson L2 残差支配，载流子块的改善
几乎不会反映在总 merit 中。

## 线搜索尺度审计

当前 Armijo 目标为 `(1-1e-4*alpha)*current_norm`。正式内存态记录如下：

| alpha | 候选残差 | 相对基态变化 | 与 Armijo 目标之差 |
|---:|---:|---:|---:|
| 1 | `1.5585850256777826e-11` | `+5.5342e-2` | `8.1879e-13` |
| 1/4 | `1.4822987153410200e-11` | `+3.6872e-3` | `5.4823e-14` |
| 1/8 | `1.4768538474144210e-11` | `+3.5510e-7` | `1.8985e-16` |
| 1/32 | `1.4768533229850917e-11` | `+5.0382e-13` | `4.6152e-17` |
| 1/4096 | `1.4768533229843530e-11` | `+3.7748e-15` | `3.6056e-19` |

从 `alpha=1/32` 开始，候选残差已进入双精度平台，但仍略高于基态，并且
Armijo 仍要求严格下降，所以继续减小阻尼不能产生可接受点。配置同时把
`stall_residual_floor` 和 `poisson_line_search_stall_residual_floor` 设为 0，
不存在平台态验收路径。

最大 Poisson 残差节点 1257 位于高掺杂 Si 区：

- `psi=1.7855343928298788 V`；
- Newton 建议的 `delta_psi=-2.2399903759697331e-16 V`，约为 `-1.009 ULP`；
- 浮点加法后的试探值为 `1.7855343928298784 V`，实际跨过 2 ULP；
- 节点残差由 `+4.594548515335986e-12` 翻转为
  `-4.566346297303233e-12`，幅值没有实质下降。

这说明尾端 Poisson 方程已经到达高掺杂电荷项消减所形成的离散浮点平台。
局部更新与残差之间不再呈现线性、连续的 Newton 关系；单纯增加回退次数或
继续减小 `alpha` 无法解决。

## 169 条载流子违规行审计

169 条均是满足 SRH/产生项限定条件后，以
`abs(row_residual)/max(flux_abs_sum, abs(source), floor)` 判定的局部行：

- 157 条电子行，12 条空穴行；169 条分布在 169 个不同节点；
- 38 条比值大于 1，85 条大于 0.9，148 条大于 0.1；
- 比值中位数为 `0.9013`，最大值为 `1.6403`；
- 违规行绝对残差范围为 `1.60e-29` 至 `1.29e-18`；
- 对应归一化尺度范围为 `9.08e-27` 至 `5.13e-14`。

最大违规节点 1888 的电子行数据为：残差 `-3.7878e-26`、通量
`-1.4786e-26`、SRH 项 `-2.3092e-26`、尺度 `2.3092e-26`。这不是大绝对
残差，而是极低电流下通量与体源项的相对闭合仍未满足 `1e-5` 门槛。

空间耦合很弱：正式 Poisson 前 10 热点中仅节点 0 同时属于载流子违规节点；
最大 Poisson 节点 1257 并非载流子违规行，最大载流子违规节点 1888 的
Poisson 残差约比最大 Poisson 热点低数千倍。因此 169 条违规不是 Poisson
热点单元直接传导产生的同一故障，而是与 Poisson 浮点平台并存的第二个精度
问题。当前 line search 首先被 Poisson merit 阻断，即使载流子方向有所改善也
无法被接受；反过来，仅放宽 Poisson 验收也不能把 169 条局部行视为已解析。

## 重启态精度发现

正式内存态写入 CSV 后再读回，同一探针得到：

- 电子块残差由 `4.60e-17` 增至 `1.17e-13`；
- 违规行由 169 增至 193；
- 线性步原始范数由正式失败时的约 `9.47` 增至约 `84.23`。

CSV 已使用 17 位十进制，问题不在文本有效位数。当前 `makeSolution` 将内部
无量纲准费米增量乘以 `potentialScale=Vt` 后保存，重启时再除以 `Vt`；该
乘除往返不能保证恢复原始 double 位模式。对接近常量的准费米场，极小边差
会被这一舍入显著改变，继而放大为 SG 通量差异。因此当前物理伏特增量和
逐节点 reference 字段仍不足以实现失败现场的逐位重演。

## 结论与后续最小任务

1. Poisson 失败根因是高掺杂节点的电荷消减/ULP 平台，加上以未归一化
   Poisson 块主导的严格 Armijo merit；不是 169 条载流子热点直接推高
   Poisson 残差。
2. 169 条载流子行代表独立的极低电流相对闭合问题，主要集中在电子方程，
   仍应保留为深关断硬门槛，不能用 Poisson stall acceptance 掩盖。
3. 下一项实现应先让失败重启保存并恢复内部缩放后的准费米坐标（或可逆的
   原始位模式），建立“内存态与重启态残差逐位一致”测试。
4. 在可复现现场上，为 Poisson 增加基于局部电荷项舍入误差/ULP 的解析度
   诊断；只有 Poisson 已达解析度平台且 169 条载流子硬门槛全部通过时，才
   允许 ULP-aware stall acceptance。
5. 载流子侧继续审计 SG 通量与 SRH 项的补偿求和及局部高精度计算；不要先
   通过放宽 `eps_row` 消除告警。

本次只增强了诊断与复现工具，没有改变正式 Newton 接受准则或 DD 物理模型。
