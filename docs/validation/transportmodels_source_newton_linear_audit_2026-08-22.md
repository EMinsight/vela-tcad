# TransportModels 深关断源端 Newton/线性求解审计（2026-08-22）

## 目标

从 DD、`Vg=-0.68 V` 的同一个扩展重启状态出发，逐层区分源端电子准费米更新是否被下列环节截断：

1. 线性求解精度；
2. 准费米更新限幅或 `max_update`；
3. 载流子对角 floor；
4. Newton 阻尼或线搜索；
5. 浮点状态更新本身。

生产默认数值设置未改变。新增的 `solver.local_update_diagnostics` 是显式启用的诊断接口，只记录指定节点的原始线性步、限幅后步、实际应用步和各阶段残差。

## 输入与节点范围

- 基础配置：`dd_m0p680000_qfref/config.json`
- 固定重启状态：`qf_reference_precision_ab_20260822/global_solve/final_state.csv`
- 源端接触边：`qf_reference_precision_ab_20260822/global_replay/contact_edges.csv`
- 审计输出：`source_newton_linear_audit_20260822/`
- 源端接触节点 22 个，相邻自由节点 26 个；其中 25 个自由节点的电子连续性行右端和线性步非零。

每组只执行一次 Newton 更新，并将绝对/相对收敛阈值及 stall floor 置零。因此算例整体显示“不收敛”是单步审计设计，不代表运行异常。

SparseLU 的全局原始线性残差为 `L2=4.4541e-26`、`Linf=2.1817e-26`。源端最大线性右端为 `5.3993e-13`，因此源端线性残差相对量级约 `1.1e-15`，足以排除 SparseLU 精度不足。SparseQR 对该系统的分解耗时过长，已停止；BiCGSTAB+ILUT 未能产生线性步。由于直接解的后验残差已经远低于源端右端，替代后端失败不影响上述判断。

0.025 V 限幅会改变器件其他位置的较大更新，所以基准组的全局“限幅后线性残差”变大；但 26 个源端相邻自由节点中没有一行的电子步被限幅，不能据此把源端问题归因于更新上限。

## 根因

源区电子准费米内部坐标采用全局接触参考：

```text
electron reference = +1.1000000000000001 V
source-region increment = -1.1000000000000001 V
physical phin = 0 V
```

源端非零原始步相对于当前 `-1.1 V` 增量的 ULP 仅为 `0.00140–0.30664` 倍，全部小于半个 ULP。于是双精度加法

```text
increment_new = increment_old + delta_increment
```

对 25 个非零源端电子步全部返回原来的 `increment_old`，实际应用步为精确的零。该舍入发生在更新候选状态形成时：

- stall/convergence floor 已置零，仍然复现；
- QF 限幅开/关不改变源端原始或限幅后步；
- 载流子对角 floor 开/关几乎不改变源端线性步；
- SparseLU 后验线性残差足够小；
- 阻尼与线搜索只能进一步缩小步长，无法恢复已低于状态 ULP 的更新。

因此，剩余问题不再是“Newton floor、更新限制或线性残差精度”，而是**全局准费米参考使源区内部增量保持在约 -1.1 V，导致深关断所需的亚 ULP 更新无法写回状态**。

## 后续实现建议

下一步应实现真正的局部/分区准费米参考，或等价的补偿增量累加器：

1. 为每个节点保存并恢复 `reference[node] + increment[node]`，源区参考取 0 V、漏区参考取 1.1 V；
2. 组装密度、SG 通量、边界条件和接触电流时始终使用节点参考与增量的稳定差分，不先重构为容易消减的全局物理值；
3. Newton 更新直接累加到局部小增量，并为参考重分区增加物理状态不变性测试；
4. 用本次相同重启状态验收：25 个非零源端步不再全部归零，源端电子通量恢复为可解析非零值，同时四端 KCL 与载流子行硬门槛通过。
