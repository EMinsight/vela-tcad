## 已修复项

- `DCSweep` 与耦合 DD 统一使用 transport-material-first 的有效本征浓度。
- 初始绝对残差不能绕过载流子行硬门槛；线搜索失败时可进入受控恢复。
- QF 守卫按对应载流子密度启用，忽略数值不可观测少数载流子的有限 QF 漂移。
- 接触多数载流子 QF 跌落只检查两端载流子密度为正且有限的输运边，排除绝缘边。
- 新增默认关闭、由本基准显式开启的载流子行合格残差地板接受路径；要求局部行、
  Poisson 地板、接触跌落和全局闭合同时满足。
- 修正 C++ BV audit 中雪崩源积分及积分电流的 SI 单位换算。
