## Interpretation

The balanced junction fixes the earlier M0 input defect and allows Vela to
reach `-20 V` on all three meshes. It does not make the present M1 topology a
valid member of a converged M1/M2 avalanche-on sequence.

The strongest evidence is not the fitted knee difference but the common M1
branch pathology:

- avalanche-off and IIC remain regular;
- self-consistent avalanche feedback produces a deterministic M1 branch jump;
- M2 is smooth and closely paired across simulators;
- source and terminal current change by orders of magnitude between M1 and M2.

This is classified as mesh-dependent avalanche branch/source behavior, not as
the resolved M0 continuation defect.

## Decision

For the original mesh-independence question, convergence is not demonstrated.
For the project-level Sentaurus-golden objective, Task 10 returns:

```text
golden_same_grid_parity_passed_mesh_observation_open
```

Task 11 may proceed using stable same-grid M0/M2 comparisons as the primary
golden evidence and retaining the M1 anomaly as a recorded nonblocking
observation. This reclassification does not itself authorize a
production-default change; SG/Laux remains opt-in pending Task 11 regression
and review.

The next useful experiment is a focused M1 topology/continuation audit:

1. run the two predeclared continuation schedules on the unchanged balanced M1
   input;
2. locate the first common departure from off/IIC in each simulator;
3. compare M1 versus M2 element quality and high-field support around that
   departure;
4. refine with an additional nested topology between M1 and M2, without
   changing dose or physics;
5. accept mesh independence only if the two finest monotonic levels satisfy
   both the `<2%` source and `<=0.10 V` knee gates.
